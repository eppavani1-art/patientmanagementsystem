
# Patient Management System

## 1. Project Overview

The Patient Management System is a web-based application developed using HTML, CSS, and JavaScript.

The main purpose of this project is to manage patient information digitally. It allows hospital staff to add, view, update, delete, and search patient records easily.

This application simplifies patient record management and reduces manual paperwork.

## 2. Technologies Used

- HTML5 – Creates the structure of the application.
- CSS3 – Provides styling and layout.
- JavaScript – Implements CRUD operations and functionality.
- LocalStorage – Stores patient records in the browser.

## 4. Features

### CRUD Operations

1. Create:
   Add new patient information, including Patient ID, Name, Age, Gender, Phone Number, and Blood Group.

2. Read:
   Display all registered patient details in a table.

3. Update:
   Edit and modify existing patient information.

4. Delete:
   Remove patient records from the system.

### Additional Features

- Search patient records.
- Validate patient information.
- Prevent duplicate Patient IDs.
- Store records using LocalStorage.
- User-friendly interface.
- Responsive design.

## 5. Installation and Setup

Step 1: Download or clone the project.

Step 2: Open the project folder in Visual Studio Code.

Step 3: Make sure the following files are available:
- index.html
- style.css
- script.js

Step 4: Install the Live Server extension in VS Code.

Step 5: Open index.html.

Step 6: Right-click and select Open with Live Server.

Step 7: The application will open in your default web browser.

## 6. How to Use

1. Open the Patient Management System.
2. Enter patient details in the registration form.
3. Click Add Patient to save a new record.
4. View patient information in the records table.
5. Click Edit to modify patient details.
6. Click Update Patient to save changes.
7. Click Delete to remove a patient record.
8. Use the search box to find specific patients.

## 7. CRUD Operations

| Operation | Description |
|-----------|-------------|
| Create | Add new patient records |
| Read | View patient records |
| Update | Modify patient information |
| Delete | Remove patient records |

## 8. Data Storage

This project uses browser LocalStorage to store patient information.

Patient records remain available after refreshing the browser in the same browser storage, unless the data is cleared.

Note: LocalStorage is used for demonstration purposes. It is not suitable for storing real or confidential hospital patient information.
